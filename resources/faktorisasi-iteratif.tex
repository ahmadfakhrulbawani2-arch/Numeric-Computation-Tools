\section{Pendahuluan}
Metode ini digunakan untuk memfaktorkan polinomial derajat tinggi secara iteratif. Untuk polinomial derajat tiga dengan bentuk umum $P(x) = x^3 + A_2x^2 + A_1x + A_0$, kita dapat memfaktorkannya menjadi bentuk:
\begin{equation}
(x + b_0)(x^2 + a_1x + a_0) = 0
\end{equation}
Tujuannya adalah menemukan nilai $b_0, a_1, \text{dan } a_0$ yang memenuhi persamaan tersebut melalui pendekatan iterasi.

\section{Penurunan Rumus Iterasi}
Jika kita mengalikan kembali $(x + b_0)(x^2 + a_1x + a_0)$, kita mendapatkan:
\begin{equation}
x^3 + (a_1 + b_0)x^2 + (a_0 + a_1b_0)x + a_0b_0 = 0
\end{equation}

Dengan menyamakan koefisien tersebut dengan persamaan asli $x^3 + A_2x^2 + A_1x + A_0$, kita peroleh sistem persamaan:
\begin{enumerate}
  \item $A_2 = a_1 + b_0 \implies a_1 = A_2 - b_0$
  \item $A_1 = a_0 + a_1b_0 \implies a_0 = A_1 - a_1b_0$
  \item $A_0 = a_0b_0 \implies b_0 = \frac{A_0}{a_0}$
\end{enumerate}

\section{Algoritma Iterasi}
Karena variabel-variabel ini saling bergantung, kita menggunakan skema iterasi dengan nilai awal tertentu (misalnya $b_0 = 0$):
\begin{itemize}
  \item \textbf{Langkah 1:} Tentukan nilai awal $b_0 = 0$.
  \item \textbf{Langkah 2:} Hitung $a_1 = A_2 - b_0$.
  \item \textbf{Langkah 3:} Hitung $a_0 = A_1 - a_1b_0$.
  \item \textbf{Langkah 4:} Perbarui nilai $b_0$ yang baru: $b_{0, \text{baru}} = \frac{A_0}{a_0}$.
  \item \textbf{Langkah 5:} Ulangi langkah 2-4 sampai nilai $b_0$ konvergen (selisihnya sangat kecil).
\end{itemize}

\section{Kelebihan dan Kekurangan}
\subsection{Kelebihan}
\begin{itemize}
  \item Memungkinkan pencarian akar polinomial sekaligus (satu akar real dan dua akar lainnya melalui rumus kuadrat).
  \item Algoritmanya sangat ringkas untuk diprogram dalam bahasa C++ atau Python.
\end{itemize}

\subsection{Kekurangan}
\begin{itemize}
  \item Sangat bergantung pada pemilihan nilai awal.
  \item Jika nilai $a_0$ mendekati nol pada saat iterasi, perhitungan $b_0$ akan menjadi tidak terdefinisi (pembagian dengan nol).
\end{itemize}
